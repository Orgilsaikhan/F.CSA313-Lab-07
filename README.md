## Хэсэг E — Дүгнэлт (debrief)

Тоогоор хамгийн үр дүнтэй нь Supermodel аялал байв — зөвхөн гадаад төрхийг харахад 6 согог (BUG-01, 03, 09, 10, 11, 14) олдсон, учир нь спецификацид UI-ийн шаардлага (улаан товч, энгийн тоон он, эвдрэхгүй хүснэгт, алдаагүй текст) олон байсан. Fed-Ex аялал нэг номыг нэмэх → хүснэгт → тоолуур → хайлт → устгах замаар дагаж 4 согог (BUG-02, 06, 07, 08) гаргасан бол Couch Potato хоосон ба зааг оролтоор 2 том баталгаажуулалтын согог (BUG-04, 05) олсон. Saboteur хамгийн цөөн буюу 2 согог (BUG-12, 13) олсон ч ноцтой байдлаараа хамгийн чухал байв: `null` бие ганцаараа серверийг унагаж, бүх өгөгдлийг устгадаг. Charter-аас гадуур санамсаргүй олдсон зүйлс: XSS шалгаж байхдаа өгөгдөл хадгалах үедээ давхар escape хийгддэгийг (BUG-10), «Нэмэx» товчны үсгийг тэмдэгтийн кодоор нь шалгахад латин x байгааг (BUG-14), мөн `null` нь хүчинтэй JSON тул «буруу JSON» туршилтаас санамсаргүйгээр уналт гарсныг дурдах нь зүйтэй. Шалгагдаагүй үлдсэн нь — нарийн дэлгэц (responsive), Tab-ийн дараалал ба хүртээмж, зэрэг хүсэлт, Зохиолч талбарын урт оролт, бодит хүний харааны шалгалт — дараагийн session-ий charter болно. Лаб 1-ийн Playwright автомат тест BUG-02 (мөрийн тоо ба тоолуурыг харьцуулах), BUG-04–08 (форм илгээж мессеж, мөрийг шалгах), BUG-11–13 (`request` контекстоор статус код шалгах), BUG-14 (`getByText('Нэмэх')` товч олохгүй) зэргийг барих байсан. Харин BUG-01 (`1,971`), BUG-03 (ногоон товч), BUG-09 (хүснэгт халих), BUG-10-ын харагдац нь тест яг тэр текст, өнгө, байршлыг урьдчилан assert хийгээгүй л бол хүний нүдээр л шууд анзаарагдана — visual regression snapshot-гүйгээр автомат тест «ажиллаж байна» гэж үзэх байсан. Эндээс exploratory тест ба автомат тест бие биеэ орлохгүй, нөхдөг гэдэг харагдсан: автомат тест мэдэгдэж буй дүрмийг давтан хамгаалдаг бол exploratory тест хэн ч тест бичиж амжаагүй зан төлөвийг олдог.
